E-Ink Retro is a client-side theme for DeepSeek Harness with two presentation modes:

- **Balanced** applies paper-and-ink surfaces while retaining semantic status colors and user media.
- **Immersive** maps supported DSH surfaces and compatibility layers to a monochrome ink ramp.

The first release includes keyboard-focus styling, local theme settings, prebuilt client bundles, bilingual documentation, and a Windows/Linux CI verification matrix.

Install the tagged release:

```sh
dsh plugin --profile web add github:exoticknight/dsh-theme-eink-retro#v0.1.0
```

See the README for compatibility boundaries, privacy details, update instructions, and rollback steps.
