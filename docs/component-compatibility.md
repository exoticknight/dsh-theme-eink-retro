# E‑Ink Retro 组件兼容检查

检查环境：DSH Desktop/Web 0.7.11、Harness 0.1.1-rc.2、dsh-context 0.31.0、dsh-dream-skin 0.4.12、dshmarket 1.26.0。首轮截图位于 [`docs/audit`](audit)，中性色与低圆角复审位于 [`docs/audit-iteration-2`](audit-iteration-2)。

状态含义：

- **实机通过**：在真实 DSH 页面切换状态并目视检查。
- **规则通过**：检查选择器、令牌或生命周期边界，并由自动测试约束。
- **宿主限制**：跨 Shadow DOM、iframe、Canvas/WebGL 的内容由组件自身控制，主题不强行侵入。

## 模式与生命周期

| 检查项 | 结果 | 结论 |
| --- | --- | --- |
| 默认平衡模式 | 实机通过 | DSH 壳层为中性浅灰/纯白/墨黑，控件与激活态为黑白；dsh-context 图表色和宠物原色保留。 |
| 完全沉浸 | 实机通过 | dsh-context 数据标记和宠物转为灰阶，正文、布局、交互不变。 |
| 暂停主题 | 实机通过 | 根属性与令牌覆盖释放，可回到原始 DSH/皮肤外观。 |
| 浅色、深色、跟随系统 | 实机通过 | 两套令牌均为中性灰阶；深色模式仍保留插件数据色。 |
| 第三方皮肤让位 | 实机通过 | 切换 dsh-dream-skin「沉静蓝」后显示暂停状态，不叠加 E‑Ink。 |
| 返回默认皮肤恢复 | 规则通过 | 针对 ThemeRuntime 重建样式表后遗留旧 disposer 的情况增加令牌哨兵与延迟重装；自动测试覆盖生命周期结构。 |
| 热重载/重复挂载 | 规则通过 | 样式表引用计数，最后一个实例卸载时才清理。 |

| --- | --- | --- | --- |

| 导航默认/悬停/激活 | 黑白反转 | 黑白反转 | 实机通过；修复过激活项黑底黑字问题。 |

| 输入框、选择框、文本域 | 中性白底、硬边 | 同左 | 实机通过；控件自身边框是唯一焦点 owner，使用黑色边框与内侧基线，不叠加 offset outline。 |

| 错误、成功、警告、业务状态 | 保留低饱和语义色 | 核心语义仍可辨 | 规则通过；错误/成功/警告不再被默认压成同一灰。 |

## 对话与内容

| 组件/内容 | 结果 | 兼容策略 |
| --- | --- | --- |
| 用户/助手气泡、引用、引用链接 | 规则通过 | 只使用官方 bubble、label、border 令牌，不猜 CSS Modules 类名。 |
| Markdown 标题、列表、表格、分隔线、引用 | 规则通过 | 沉浸规则只改已有内容表面与边线，不生成结构。 |
| 行内代码、代码块、Shiki 高亮 | 规则通过 | 平衡模式不滤高亮色；沉浸模式只统一容器，不对代码内容套全局滤镜。 |
| Diff、工具调用、命令卡、终端输出 | 规则通过 | 由官方 label/bg/border/state 令牌承接；不改成 TUI 或终端主题。 |
| 图片、附件预览、视频 | 规则通过 | 明确排除全局 `img`/`video`/媒体滤镜。 |
| Canvas/WebGL 图表 | 宿主限制 | 平衡模式原样保留；沉浸模式不截图后处理，避免破坏可读性和性能。 |

## 第三方插件与扩展边界

| 类型 | 平衡模式 | 完全沉浸 | 备注 |
| --- | --- | --- | --- |
| 使用 DSH 语义令牌的插件 | 自动统一壳层 | 自动统一壳层 | 推荐兼容路径。 |
| 硬编码 DOM/SVG 颜色的插件 | 保留自身颜色 | 只对已验证适配器灰阶 | 当前适配 dsh-context 0.31.x。 |
| 宠物、装饰皮肤 | 保留原色 | 仅命中特定 skin/pet 资源路径时灰阶 | 不影响普通消息图片。 |
| Shadow DOM | 保留自身主题 | 不强穿透 | 需插件提供令牌或主题 API。 |
| iframe | 保留自身主题 | 不跨文档改色 | 避免安全与品牌兼容问题。 |
| Portal 弹层 | 官方令牌统一 | 官方令牌+沉浸边线 | 避免依赖 `body:has()`。 |

## 已移除的高风险写法

- 删除全局综合色与第三方 `--aion-*` 私有令牌覆盖。
- 删除 `body:has(...)` 页面级选择器。
- 删除默认模式下的 `grayscale()`；所有灰阶适配都限定在 `html[data-dsh-theme-eink-retro="immersive"]`。
- 不对所有 `img`、`svg`、`canvas`、`video` 或用户内容应用滤镜。
- 不新增菜单栏、终端框架、TUI 装饰或伪元素生成的应用结构。

## 回归入口

1. 设置 → E‑Ink Retro，依次切换平衡、完全沉浸、暂停。
2. 通用设置 → 外观，检查浅色、深色、跟随系统。
3. Theme / 外观，切换任一第三方皮肤，再回到默认，确认 E‑Ink 自动让位和恢复。
4. 打开 dsh-context、插件市场、含代码/表格/图片的对话，确认数据色、内容色与壳层职责没有混淆。
5. 打开任务看板、SSH、Skill Center，检查激活态文字、开关轨道、标签和搜索框外壳没有恢复圆角或旧主题颜色。
