# E-Ink Retro v0.3.3

This patch release adds compatibility with DSH 0.2.0-rc.2 while retaining the existing 0.1.7-rc.1 line.

## Changes

- Declare support for DSH 0.2.0-rc.2.

## Install or update

```sh
dsh plugin --profile web add github:exoticknight/dsh-theme-eink-retro#v0.3.3
```

Restart DSH Web after changing versions, then open **Settings → E-Ink Retro**.
