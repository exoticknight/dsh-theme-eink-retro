# E-Ink Retro v0.2.1

## Changes

- Skill management switches now use the same crisp paper-and-ink track and square thumb as other DSH switches.
- Selected tabs keep their native underline without an extra gray background.
- The composer keeps one outer frame after DSH's input structure changes, both at rest and during keyboard focus.

## Install or update

```sh
dsh plugin --profile web add github:exoticknight/dsh-theme-eink-retro#v0.2.1
```

Restart DSH Web after changing versions, then open **Settings → E-Ink Retro**.
