# E-Ink Retro v0.2.0

## Changes

- You see English or Simplified Chinese settings based on the page or browser language.
- You can identify selected question choices by their quiet paper row and inverse number or check marker.
- Custom question answers have one input frame for their resting, hover, and keyboard focus states.
- Session tabs keep the DSH selected underline and add paper-and-ink hover and focus treatments.

## Install or update

```sh
dsh plugin --profile web add github:exoticknight/dsh-theme-eink-retro#v0.2.0
```

Restart DSH Web after changing versions, then open **Settings → E-Ink Retro**.
