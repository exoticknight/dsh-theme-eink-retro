# DeepSeek Harness E‑Ink Retro 主题

[English](README.md) | [简体中文](README.zh-CN.md)

E‑Ink Retro 是面向 DeepSeek Harness（DSH）的客户端主题插件。它的设计语言是纸与墨：中性灰的界面、纯黑的文字、硬边偏移阴影、方角控件，选中状态在黑与白之间翻转。几何取自经典 Macintosh，落在现代界面上，安静而克制。

## 适用人群

- 长时间使用 DSH、希望界面安静克制、少一些视觉干扰的人
- 喜欢纸墨质感界面的人：灰纸底色、黑色文字、克制的用色
- 欣赏经典 Macintosh 几何、并希望它出现在现代应用里的人

## 主题会改变什么

- 纸墨色板：浅色 `#f4f4f4` 纸面配 `#161616` 墨色，深色 `#181818` 配 `#f4f4f4`，保持纯粹中性
- 控件与面板统一 2px 圆角
- 1px / 2px 硬边偏移阴影，像印刷品一样平贴页面
- 选中状态在黑与白之间整块翻转
- 开关是矩形轨道加方形滑块
- 对话输入框、搜索框、输入框、下拉框共用同一套焦点框
- 对话浮层与轨迹页的滚动区域稳定
- 对话、上下文、设置、任务面板、SSH、技能中心、插件市场、工房页面均有验证过的适配
- 卸载时注入的 token 与样式一并清除

## 模式

| 模式 | 说明 |
| --- | --- |
| **平衡**（默认） | 应用纸墨外壳和控件语言。保留有实际含义的语义色：状态色、图表色、品牌色和内容色以低饱和度保留。 |
| **沉浸** | 只对验证过的装饰层和兼容层做灰度处理。图片、附件、视频等用户内容保持原样。 |
| **关闭** | 通过设置页的原生复选框移除全部主题 token 和 CSS 覆盖。插件保持安装状态。 |

两种模式都支持 DSH 内置的跟随系统、浅色和深色主题。选择第三方主题时，E‑Ink Retro 会自动暂停；切回内置主题后，恢复此前的模式。

## 从源码安装

需要：

- Node.js 20 或更高版本
- 已安装 DSH，并可使用 `web` profile

克隆或下载本仓库，然后运行：

```sh
npm install
npm run build
```

把构建产物链接到 DSH。请将示例路径替换为本仓库的绝对路径：

```sh
dsh plugin --profile web add link:/absolute/path/to/dsh-theme-eink-retro
```

Windows 示例：

```powershell
dsh plugin --profile web add link:C:/path/to/dsh-theme-eink-retro
```

链接完成后重新加载 DSH。

## 使用

打开 **设置 → E‑Ink Retro**。用原生复选框启用主题，然后选择平衡或沉浸模式。选择保存在当前 DSH profile 使用的浏览器中。

建议先用平衡模式。确认常用页面和插件在黑白显示下正常后，再切换到沉浸模式。需要与 DSH 原始界面对比时，清除启用复选框。

## 兼容边界

主题通过 DSH 的语义颜色系统和经过验证的公共组件工作。基于 DSH 语义变量的组件直接继承主题色板。

主题只改自己验证过的表面，其余保持原样：

- 图片、附件、视频、Canvas 输出和 iframe 内容保持原始渲染。
- 原生下拉菜单展开后可能使用操作系统样式。
- 使用硬编码颜色、Shadow DOM 或独立渲染层的插件只继承部分主题。
- 平衡模式保留承载状态或信息的低饱和度语义色。

## 常见问题

**平衡模式为什么保留颜色？**
低饱和度语义色让状态信息保持可区分。沉浸模式提供完整的黑白效果。

**Macintosh 的影响体现在哪里？**
几何与反白选中沿用经典 Macintosh；布局与交互仍是现代 DSH。

**会影响插件内容吗？**
主题只改验证过的表面。图片、附件、视频、Canvas、iframe 保持原始渲染；使用 Shadow DOM 或硬编码颜色的插件只继承部分主题。

**有性能开销吗？**
主题是一份样式表加一次 token 覆盖，仅在主题切换时同步。

**卸载后会留下残留吗？**
卸载时注入的样式节点和 token 覆盖会被移除。

## 开发与维护

提交修改前运行完整检查：

```sh
npm run check
```

该命令执行 TypeScript 检查、回归测试和正式构建。构建结果写入 `lib/index.js` 和 `lib/client.js`。

主要实现文件：

- `src/client/tokens.ts`：浅色和深色模式使用的语义颜色
- `src/theme.css`：组件几何、交互状态和兼容适配
- `src/client/index.ts`：模式存储、DSH 主题协调、设置界面和卸载清理
- `tests/theme.test.mjs`：包结构与主题边界回归检查

新增 CSS 应限制在 `html[data-dsh-theme-eink-retro]` 下。只用于黑白沉浸模式的适配放在 `immersive` 属性选择器下。不要加全局媒体滤镜，也不要依赖构建生成的 class 哈希。
