# DeepSeek Harness E-Ink Retro 主题

[English](README.md) | [简体中文](README.zh-CN.md)

E-Ink Retro 是面向 DeepSeek Harness（DSH）的客户端主题插件。它用中性的界面底色、黑白控件、清晰边框和紧凑几何，构成清晰、克制、专注的使用界面。

主题保留 DSH 原有的布局和操作流程，只调整语义颜色和经过验证的组件样式。它不会把 DSH 改成终端界面，也不会照搬复古桌面。经典 Macintosh 设计只用于提炼信息层级和控件形态，最终界面仍服务于现代应用。

## 主题会改变什么

- 中性的明暗色板，不使用米色纸张背景，也不带绿色偏色
- 方正、低圆角的控件和界面容器
- 按钮、标签页和开关使用明确的黑白选中状态
- 对话输入框、搜索框、普通输入框和下拉框使用统一焦点边框
- 对话浮层和轨迹页面使用稳定的滚动区域，不因滚动条出现或消失而跳动
- 适配 DSH 的对话、上下文、设置、任务面板、SSH、技能中心、插件市场和工房页面
- 插件卸载时自动清除注入的颜色变量和样式

## 模式

| 模式 | 适合场景 | 颜色处理 |
| --- | --- | --- |
| **平衡** | 默认模式，适合日常使用和包含多种插件内容的页面。 | 使用 E-Ink 的框架和控件语言，同时保留有实际含义的状态色、图表色、品牌色和内容色。 |
| **沉浸** | 适合希望界面更接近完整黑白效果时使用。 | 只对经过验证的装饰区域和兼容层增加灰度处理，用户媒体内容保持原样。 |
| **关闭** | 通过设置页中的原生复选框临时停用主题，但不卸载插件。 | 移除本主题覆盖的颜色变量和 CSS。 |

平衡和沉浸模式都支持 DSH 内置的跟随系统、浅色和深色主题。选择其他第三方主题时，E-Ink Retro 会自动让出样式控制；切回 DSH 内置主题后，会恢复此前选择的 E-Ink 模式。

## 从源码安装

需要：

- Node.js 20 或更高版本
- 已安装 DSH，并可使用 `web` profile

克隆或下载本仓库，然后运行：

```sh
npm install
npm run build
```

把构建后的插件链接到 DSH。请将示例路径替换为本仓库的绝对路径：

```sh
dsh plugin --profile web add link:/absolute/path/to/dsh-theme-eink-retro
```

Windows 示例：

```powershell
dsh plugin --profile web add link:C:/path/to/dsh-theme-eink-retro
```

链接完成后重新加载 DSH。

## 使用

打开 **设置 → E-Ink Retro**，使用原生复选框启用或关闭主题。启用后可以选择平衡或沉浸模式。选择结果会保存在当前 DSH profile 使用的浏览器中。

建议先使用平衡模式。确认当前页面和插件适合黑白显示后，再切换到沉浸模式。需要与 DSH 原始界面对比时，可以清除启用复选框。

## 兼容边界

主题主要作用于 DSH 的语义颜色系统和经过验证的公共组件。使用 DSH 语义变量的组件通常可以直接继承主题色板。

以下内容仍由原应用、插件或操作系统控制：

- 图片、附件、视频、Canvas 输出和 iframe 内容不会被全局灰度处理。
- 原生下拉菜单展开后，可能显示操作系统提供的样式。
- 使用硬编码颜色、Shadow DOM 或独立渲染层的插件，可能只能继承部分主题样式。
- 如果去掉颜色会损失状态或信息含义，平衡模式会保留低饱和度语义色。

这些边界用于保护内容，并避免在没有验证的情况下改变其他插件的界面。

## 开发与维护

提交修改前运行完整检查：

```sh
npm run check
```

该命令会执行 TypeScript 检查、回归测试和正式构建。构建结果写入 `lib/index.js` 和 `lib/client.js`。

主要实现文件：

- `src/client/tokens.ts`：浅色和深色模式使用的语义颜色
- `src/theme.css`：组件几何、交互状态和兼容适配
- `src/client/index.ts`：模式存储、DSH 主题协调、设置界面和卸载清理
- `tests/theme.test.mjs`：包结构与主题边界回归检查

新增 CSS 应限制在 `html[data-dsh-theme-eink-retro]` 下。只用于黑白沉浸模式的适配应放在 `immersive` 属性选择器下。不要增加全局媒体滤镜，也不要依赖构建过程生成的 class 哈希。
